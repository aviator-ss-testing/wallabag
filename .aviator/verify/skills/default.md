# Wallabag verify guidance

Wallabag is a self-hosted "read it later" / bookmarking app. The preview serves
the full web UI at the preview URL; everything past the login screen requires
authentication.

Read both of these files (in this same directory) before planning or driving:

- **`auth.md`** — how to sign in: credentials and the login flow.
- **`app.md`** — getting around the app, and what the preview can and can't
  exercise as evidence.
